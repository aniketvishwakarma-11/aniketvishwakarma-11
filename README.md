### 🎓 Student Placement Prediction System
**`[ LIVE · 197+ USERS · 4,400+ VIEWS ]`**

<img src="https://img.shields.io/badge/Status-Live%20%26%20Growing-22c55e?style=flat-square"/> <img src="https://img.shields.io/badge/Users-197%2B-a78bfa?style=flat-square"/> <img src="https://img.shields.io/badge/Avg%20Session-6m%205s-3b82f6?style=flat-square"/> <img src="https://img.shields.io/badge/Events-6%2C700%2B-f97316?style=flat-square"/>

A full-stack AI platform that predicts student placement probability using trained ML models. Not a tutorial clone — a real platform with real users and measurable impact.

**What makes it different:**
- 🤖 **Dual AI engine** — Gemini 2.5 primary, Cloudflare Workers AI as automatic fallback
- 📄 **Resume ATS scorer** (0–100 scale) using Affinda Resume Parser
- 📊 **Role-based dashboards** for students, faculty, and placement officers
- 🧠 **Two prediction modes** — standard form-based and resume-upload-based ML inference
- 💬 **AI chatbot counselor** with personalized career recommendations
- 📈 **Trend visualizations** with Recharts

### ♻️ EcoVision Bharat — Waste Management Platform
**`[ 🏆 GNA HACKATHON 4.0 WINNER · DOMAIN: CLEAN & GREEN TECHNOLOGY ]`**

<img src="https://img.shields.io/badge/Award-1st%20Prize-fbbf24?style=flat-square"/> <img src="https://img.shields.io/badge/AI-YOLOv8%20Inference-ef4444?style=flat-square"/> <img src="https://img.shields.io/badge/Roles-3%20User%20Types-8b5cf6?style=flat-square"/>

AI-powered civic waste management. Citizens report waste with photos + GPS. Officers verify and dispatch. Sanitation workers track progress. YOLOv8 handles severity estimation automatically.

**What makes it different:**
- 🎯 **YOLOv8 ML inference** for real-time waste severity classification
- 🗺️ **GPS geolocation** with OpenStreetMap integration
- 👥 **3-role workflow:** Citizen → Officer → Worker
- 🎮 **Gamified scoring** to drive citizen participation
- ⚡ **FastAPI + Python** backend for ML serving

| ML / AI | YOLOv8 · Python inference pipeline |
| Database | Supabase · PostgreSQL |
| Media | Cloudinary · OpenStreetMap |
